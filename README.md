# Personalkostenrechner

Ein kleines Python-Programm, das die Personalkosten für einen Mitarbeiter
aus Arbeitsstunden und Stundensatz berechnet.

## Funktionen
- Abfrage von Mitarbeitername, Stunden und Stundensatz
- Eingabe mit Komma oder Punkt möglich (z. B. 12,50 oder 12.50)
- Ausgabe der Personalkosten mit zwei Nachkommastellen

## Starten
Python 3 installieren und im Terminal ausführen:

    python Personalkostenrechner_v0.1.py
